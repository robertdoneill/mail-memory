# Changelog

## 0.1.1

- Snippets are cleaner. They drop links, tracking ids and separator lines, and highlight the words that
  matched.
- Each result shows the sender's name, the date, the attachment the match came from, and how many messages
  in the conversation matched.
- The default number of results is now 10, and you can set up to 20.

## 0.1.0

- First release. Adds conversations found by meaning to Bulwark's search, through a Mail Memory server.
